Subtitle Cleaner membantu merapikan file subtitle `.srt`: menghapus tag sisa, baris kosong berlebih, dan memperbaiki penomoran otomatis.

**Cara pakai singkat:**
1. Download dan ekstrak file zip.
2. Jalankan aplikasi, pilih file `.srt`.
3. Klik **Bersihkan**, hasil tersimpan di folder yang sama.

Butuh bantuan atau punya saran fitur? Hubungi admin lewat tombol di samping.
