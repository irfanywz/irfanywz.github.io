Sudah 3 minggu lebih saya tidak menyentuh kode

terakhir melihat kode yaitu ketika membuat aplikasi music max 

ini saya lakukan untuk membuat fokus berubah, agar mengerjakan hal-hal yang lebih diprioritaskan

selama ini saya bermain dengan kode hanya karena ingin mempermudah pekerjaan, padahal nyatanya bermain kode hanya membuang waktu. 

saya mulai paham kenapa saya selalu suka buat aplikasi, tapi aplikasinya tidak sepenuhnya digunakan.

ini karena fokus saya hanya membuat saja, saya meniru dari orang lain karena ingin bisa membuatnya juga.

seolah-olah aplikasinya bakal saya gunakan nyatanya tidak sampai sekarang, hanya beberapa aplikasi yang benar-benar saya gunakan


...

dari evaluasi ini saya belajar bahwa saya sudah membuang banyak waktu tanpa ada hasil dari tujuan sebenarnya

harusnya yang saya lakukan adalah fokus pada prioritas utama, bukan mengembangkan aplikasi

disini malah dibalik, saya buat aplikasi. baru mengerjakan prioritas utama

jadinya waktu seperti terbuang dengan sia-sia, tanpa ada hasil nyata 

nyatanya saya tidak ada channel yang saya kembangkan satupun, buat kontenpun cuma beberapa doang abis itu ditinggalkan

ini semua terjadi karena fokus saya terpecah menjadi 2, kalau terus terusan seperti ini rasanya saya tidak akan menghasilkan apa-apa

...

setelah berhenti bermain dengan kode

yang saya rasakan sekarang ini, saya merasa memiliki banyak waktu tanpa memikirkan kode yang rumit, saya bisa mengatur rencana untuk mengerjakan tugas prioritas, merapihkan data, memulai melamar pekerjaan lagi, dan sebagainya

bermain dengan kode memang benar-benar menguras waktu dan energi, saya seperti terjebak oleh ilusi virtual yang tiada henti

mungkin cukup sampai disini, dan akan saya batasi untuk perkodean ini, cukup sudah waktu yang terbuang, 

kalau memang dibutuhkan untuk kembali bermain dengan kode saya pastikan hasilnya yang memang akan membantu saya dalam menyelesaikan pekerjaan 


...

saya juga ada niatan untuk memberikan aplikasi yang saya buat secara gratis, agar aplikasi tidak sia-sia begitu saja dan bermanfaat
