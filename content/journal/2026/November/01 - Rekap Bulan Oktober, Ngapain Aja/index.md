bulan oktober kemarin rasanya seperti seminggu

seinget saya padahal lagi fokus benerin web dengan nambah menu musik yang butuh integrasi ai didalamnya

eh gak taunya malah kebablasan buat banyak aplikasi

full 1 bulan oktober saya melakukan vibe coding, dan hasilnya ?

benar-benar gila !

yang dulunya saya kerjain secara hybrid, sekarang ternyata sudah bisa full otomatis

saya tidak lagi melihat kode, hanya mengarang cerita dan aplikasi jadi seketika

kalau ada bug ? tinggal perintahin "ada bug di x". ai langsung benerin

...

1 bulan belakangan ini saya benar benar ngulik ai untuk koding, 

awal mulanya berasal dari web saya yang ingin menyimpan daftar prompt untuk kebutuhan animasi

saya mencoba ai untuk membuatkannya, dan hasilnya saat itu sudah jadi hanya sebatas kumpulan prompt dan ada fitur databasenya

namun ternyata itu belum cukup, saat itu saya menambah halaman musik dengan tujuan untuk menyimpan berbagai prompt musik

namun tiba-tiba terlintas dalam kepala, daripada cuma nyimpen prompt terus dilempar kenapa gak sekalian di-integrasiin ada ai didalamnya, jadi bisa langsung generate ? inilah titik awal mulanya

awalnya saya membuatnya digemini, namun pas pindah ke provider viber coding kasta tertinggi yaitu claude.ai, semua berubah

aplikasi prompt yang dulunya cuma buat nyimpen prompt sekarang bisa langsung generate hasilnya juga

claude ai benar-benar membuat jiwa membuat sesuatu saya keluar, alhasil full 1 bulan kemarin saya vibe coding membuat banyak aplikasi

kira-kira totalnya 10 lebih dan semua ditujukan untuk membuat konten musik, untuk daftar aplikasinya sebagai berikut

- Audio Spektrum, awalnya dibuat di aistudio google, tapi pas pindah keclaude semua benar-benar terasa berbeda

- AudioTransforam, buat diaistudio, awalnya bisa tambah fitur untuk bypass suno, tapi pas diclaude dia gak mau nerima fitur itu alhasil dihapus

- Playlist Marger, dibuat diaistudio, fungsinya tidak banyak hanya menggabungkan beberapa musik jadi satu dan mendapatkan timestampnya

- VidSlicer, ini juga dibuat diaistudio, cuma buat motong video didurasi tertentu bisa buat ngambil beberapa bagian doang, bisa untuk seamless loop video juga

- SingSlicer, dibuat diaistudio, untuk memisah musik playlist jadi satuan

- ZeroMuxe. dibuat diaistudio, fungsinya buat menggabungkan audio dan video mp4 tanpa encoding ulang

- MazCrum, dibuat diclaude, berfungsi untuk manajemen profil chrome dan manajemen link 

- MazCompo, dibuat diclaude, berguna untuk video compositing secara masal

- VoiceCooked, dibuat diclaude, berguna buat memisah voice over berdialog jadi file terpisah untuk kebutuhan animasi

- Transkriboy & Transkrigroq, dibuat digemini, untuk melakukan trascript audio, ada yang menggunakan local model dan api

- AudioFiseh, dibuat diclaude, untuk memisah vokal dan instrumental

- Dondoen, dibuat diclaude, untuk melakukan pengunduhan media

- TubyuTracer, dibuat diaistudio kemudian dipidah ke claude, untuk riset konten youtube

- TubyuSentral, dibuat diclaude, untuk manajemen channel youtube multi profile chrome

- TubyuAplod, addons untuk tubyu sentral yang dibuat diclaude, berfungsi untuk otomatisasi upload

...

kesimpulan yang saya bisa ambil, desain hasil aistudio milik google rasanya seperti slop atau terlalu modern. karena bisa di-identifikasi dengan ciri khasnya yaitu dark dan neon. 

kalau claude ? dia terlalu basic, kalau gak diperintahin atau gak dikasih referensi dia terlalu basic, tapi urusan proses atau logikanya tidak diragukan lagi, minim bug sama sekali

dari kedua provider ini punya kelebihan dan kekurangannya masing masing, di aistudio masih bisa melakukan yang ada kriminalnya, tapi diclaude ai semua diblokir

misalnya saya ingin membuat aplikasi untuk melakukan hal yang ilegal, di aistudio bisa dibuatkan, sedangkan diclaude ai tidak mau
