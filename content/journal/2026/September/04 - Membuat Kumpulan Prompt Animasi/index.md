hari-hari sebelumnya saya sempat mengulik animasi lagi, saya membuat beberapa prompt untuk mempercepat produksi aset seperti karakter, background, objek

prompt yang saya kumpulkan disimpan masih berupa file dengan nama promptnya

misal nama filenya karakter_prompt > isinya berupa base prompt untuk buat karakter

semakin lama file prompt semakin banyak dan membuat saya mencari pendekatan lain

dan saya menemukan cara yang sama seperti saya menyimpan prompt koleksi-koleksi saya, yaitu menaruhnya diweb

namun kali ini saya membuat halaman khusus untuk animasi, selain berisi prompt saya juga menambahkan video terakhir yang difetch lewat feed youtube, dan halaman naskah yang isinya berupa script dialog yang akan saya gunakan nantinya dalam pembuatan animasi
