setelah sebelumnya saya membuat kumpulan prompt animasi diweb, saya merasa ada ketidak enakan saat menggunakanya

karena base promptnya masih terpisah pisah padahal tujuannya sama

misal saya punya base prompt membuat karakter, lalu ada prompt membuat deskripsi karakter dan deskripsi karakter dari referensi gambar

ke-3 prompt ini saya buat terpisah untuk setiap halamannya, dan membuat terlalu banyak halaman

karena tujuannya sama, yaitu outputnya untuk membuat karakter maka saya mencoba merombak total promptnya

kali ini saya satukan ke 3 base prompt tersebut menjadi 1 halaman

dengan begini penggunakan prompt akan lebih mudah

ketika saya mau buat karakter dari referensi gambar, saya tinggal copas prompt deskripsi gambar, kemudian memasukannya kebase prompt pembuatan karakter

yang ingin mencoba promptnya bisa mengunjungi link [prompt animasi ini](/animasi/?tab=prompt)
