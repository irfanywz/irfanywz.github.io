## Cara memakai saat pindah web chat
1. Unggah zip (atau tempel isi `AI_MEMORY/`) ke chat baru.
2. Tempel isi `PROMPT_RESUME.md` dan isi bagian "Tugas saya sekarang".
3. AI baru akan membaca `AI_HANDOFF.md` lebih dulu dan hanya membuka file lain bila perlu.
4. Sebelum pindah lagi, minta AI memperbarui `AI_HANDOFF.md` dan `CURRENT_TASK.md`.
