outputs: ["JSON"]

Gua mau melanjutkan proyek ini di chat AI lain karena sesi ini akan berakhir.

Perbarui folder `AI_MEMORY/` berdasarkan kondisi proyek paling baru. Catat fitur yang selesai, perubahan kode, keputusan penting, bug yang tersisa, tugas yang sedang dikerjakan, dan langkah selanjutnya.

Pastikan `AI_HANDOFF.md` berisi ringkasan praktis agar AI berikutnya bisa langsung melanjutkan tanpa membaca ulang seluruh percakapan.

Jangan hanya menampilkan isi catatan di chat. Perbarui file yang sebenarnya dan beri tahu gua file mana yang berubah serta apakah gua perlu mengunduh ulang proyek.

Jangan mengklaim file sudah diperbarui jika belum benar-benar dilakukan.
